# sanjose-ai-transit-access
Addressing inaccessibility of reporting issues with the VTA for non-English speaking riders. 

[Transit Translation]: AI for multilingual reporting with the Valley Transit Authority(VTA). 
Team: [Sumit Chhabra, Brandon Daniel, Andrew Rivas, Santos Sandoval], Aug-Oct 2026
My part: ["I designed and built the relational database and determined what governance is required for the app to succeed."]

## The Problem
[Riders who aren't fluent in English struggling to access the VTA and report issues they've experienced with the bus or light rail services.]

## What we built
- Reporting software with input options for English, Vietnamese, Spanish, and Panjabi.
- User able to describe the problem, the issue that took place, what the route was(e.g., Rapid 500 to Berryessa), what stop it occurred, and an image of the issue/incident.
- VTA decides who’s in charge of specific issues and what kind of intervention is needed to resolve it. 

## What I would do next
[Update app so users can login with existing VTA accounts and implement multi-factor authentication.]
