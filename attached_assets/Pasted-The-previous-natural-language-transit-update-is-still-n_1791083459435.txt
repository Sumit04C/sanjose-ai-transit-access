- “The bus never showed up.”

Winchester

1. Extract the station name from the rider's sentence.
2. Search the available VTA stop/station data using case-insensitive and partial-name matching.
3. Rank matching stops by name similarity and transit mode.

5. If one station is clearly the best match, automatically use its stop ID.
6. If multiple directions/platforms exist but the next-departure query can be checked across all of them, query them first instead of immediately asking the rider.
